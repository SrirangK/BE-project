## Critical Reviewer Issues to Address

### Reviewer 1 - Abstract Problems (URGENT)
**Current Issues:**
1. Too much detail (literature review, section content mixed in)
2. Research gap not clearly stated
3. Contributions unclear (is this a survey or framework?)
4. Formatting errors (typos, inconsistent capitalization)
5. Two-stage architecture benefit not explained
6. No concluding impact statement

**Required Actions:**
- Rewrite abstract (150-200 words) with:
  - Clear problem statement
  - Single sentence on research gap
  - 2-3 concise contribution bullets
  - Explanation of how two-stage approach improves over existing methods
  - Expected outcomes/impact
- Proofread carefully for typos

### Reviewer 2 - Methodology Rigor (IMPORTANT)
**Current Issues:**
1. Lacks mathematical rigor
2. Re-ranking semantics not elaborated
3. Importance of semantic re-ranking unclear

**Required Actions:**
- Add mathematical formulations:
  - Clustering algorithm (if using K-means, add formula)
  - Similarity scoring (cosine similarity formula)
  - Re-ranking mechanism (clear mathematical definition)
- Add subsection explaining why semantic re-ranking matters
- Include complexity analysis

## Formatting Checklist
- [ ] All figures have titles
- [ ] All figures cited in text
- [ ] External figure sources cited after title
- [ ] All tables have titles
- [ ] All tables cited in text
- [ ] IEEE style references (CRITICAL)
- [ ] Reference format: Author, "Title", Journal, Year, Vol, Issue, Pages
- [ ] No duplicate references
- [ ] All in-text citations match reference list
- [ ] Citations in numerical order [1] before [2]
- [ ] All authors listed with affiliations and email IDs

## Structure to Follow
1. **Abstract** (rewritten - ~200 words)
2. **Introduction** (motivate the problem)
3. **Literature Survey** (brief, cite properly)
4. **Proposed Methodology** (with math formulations)
5. **Experimental Setup or Architecture Details**
6. **Results/Discussion** (if applicable)
7. **Conclusion**
8. **References** (IEEE format)
